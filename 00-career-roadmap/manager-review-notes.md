## How to Use This File

**Before each review:**
1. Pull the corresponding packet from `07-manager-review-packets/`
2. List 3 things you want your manager to know
3. List 1 ask (resource, visibility, opportunity)
4. Anticipate 1 tough question and prepare your answer

**After each review:**
1. Note any feedback received
2. Note any commitments made
3. Update the skills matrix if any gaps were named
4. Adjust the 6-month plan if priorities shifted
